# 遷移至 Safe Global

Kaia 先前曾營運 **Kaia Safe**（`safe.kaia.io`），這是 Gnosis Safe 的託管分支版本。該介面已於 **2026年8月31日** 停止使用，目前已無法使用。

[Safe Global](https://app.safe.global) 原生支援 Kaia 主網和 Kairos 測試網。透過 [app.safe.global](https://app.safe.global) 上的「Safe Wallet」，在 Kaia 上建立及管理「Safe」。

## 您現有的 Safe 帳戶不會受到影響

「Your Safe」是 Kaia 上的智慧合約。停用由 Kaia 託管的介面僅變更了 **網頁前端**，並未影響您的鏈上帳戶。

未變更：

- 安全地址
- 所有者與確認門檻
- 資產（KAIA、代幣、NFT）
- 鏈上交易紀錄

您**無需**重新部署、重新建立，或將資金移轉至新的「安全庫」。透過 Kaia Safe 建立的保險箱，只要您連線至擁有者錢包，就會立即出現在 Safe Global 上。

## 在 Safe Global 上開啟您現有的保險箱

1. 開啟 [app.safe.global](https://app.safe.global)。
2. 請連接一個身為您「保險箱」**擁有者**的錢包（例如 Kaia Wallet 或 MetaMask）。
3. 您的「安全箱」應會出現，並標示其所屬的網路（**Kaia** 或 **Kairos**）。如果沒有，請前往 [app.safe.global/welcome/accounts](https://app.safe.global/welcome/accounts)，並點擊 **管理清單**，以查看與您已連線的錢包相關聯的 Safes。

## 通訊錄標籤

通訊錄——也就是您為地址儲存的名稱和標籤——是儲存在 `safe.kaia.io` 介面的本地端，而非鏈上，而這正是唯一無法自動轉移的內容。由於該介面已停用，儲存的標籤將無法再匯出，必須在「Safe Wallet」的**通訊錄**中重新輸入。

這僅影響標籤。持有權、餘額及交易紀錄皆儲存於區塊鏈上，且不受影響。
