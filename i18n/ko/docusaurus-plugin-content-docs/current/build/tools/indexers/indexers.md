# Indexers

블록체인 인덱서는 블록체인 기술에 사용되는 도구로, 블록체인에 저장된 데이터의 검색, 쿼리, 액세스의 효율성과 속도를 개선합니다. 블록체인 데이터의 체계적인 데이터베이스를 생성하고 유지하여 사용자가 전체 블록체인을 처음부터 처리할 필요 없이 정보를 빠르게 검색할 수 있도록 합니다.

:::caution The Graph는 2026년 8월 31일에 Kaia에서 서비스를 종료합니다.

[The Graph](https://thegraph.com/)에서의 Kaia 지원은 **2026년 8월 31일**에 종료됩니다. 해당 날짜가 지나면 카이아 서브그래프의 색인 생성이 중단되고, 해당 쿼리 엔드포인트에서 데이터를 반환하지 않게 됩니다. 사용 중인 DApp이 해당 그래프에 의존하고 있다면, \*\*[The Graph에서 마이그레이션하기](./migrate-from-the-graph.md)\*\*를 참조하세요. 서브그래프 코드는 수정 없이 Goldsky, SubQuery 또는 자체 호스팅 그래프 노드로 그대로 이관됩니다.

:::

Kaia와 통합하여 블록체인 인덱싱 서비스를 제공하는 공급자는 다음과 같습니다:

| 제공자                        | 카이아 네트워크                       | 참고 사항                                                                                                            |
| -------------------------- | ------------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| [Goldsky](./goldsky.md)    | 메인넷, 카이로스                      | 관리형 하위 그래프 및 미러 데이터 스트리밍. 서브그래프 사양과 호환되므로, 기존 서브그래프는 단일 CLI 명령어로 마이그레이션할 수 있습니다. |
| [SubQuery](./subquery.md)  | 메인넷, 카이로스                      | 단일 프로젝트 내에서 멀티 체인 인덱싱을 지원하며, 관리형 및 탈중앙화 네트워크 호스팅을 제공합니다.                                         |
| [The Graph](./thegraph.md) | 메인넷, 카이로스 — **2026년 8월 31일까지** | 카이아의 석양. [The Graph에서 마이그레이션하기](./migrate-from-the-graph.md)를 참조하세요.             |

직접 인덱싱 인프라를 운영하고 싶다면, Kaia 아카이브 RPC 엔드포인트를 대상으로 [graph-node](https://github.com/graphprotocol/graph-node)를 직접 실행할 수도 있습니다.
