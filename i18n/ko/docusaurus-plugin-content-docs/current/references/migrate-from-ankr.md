# Ankr에서 마이그레이션하기

:::caution 일몰 공고

**Ankr**에서의 Kaia 지원은 **2026년 10월 16일**에 종료됩니다. 해당 날짜 이후, 카이아 체인을 가리키는 모든 Ankr RPC 엔드포인트는 서비스가 중단되어 응답하지 않게 됩니다.

앱에서 Ankr로 Kaia RPC 호출을 전송하는 경우, 서비스 종료일 전에 다른 제공업체로 전환하십시오. 대부분의 프로젝트에서 이는 단 한 줄의 엔드포인트 변경만으로 해결됩니다. 자세한 내용은 [대안 선택하기](#choose-an-alternative)를 참조하세요.

:::

## 무엇이 바뀌고 있는가

Ankr는 Kaia RPC 서비스를 중단합니다. 이는 엔드포인트에만 영향을 미치며, Kaia 자체에는 아무런 변화가 없습니다.

| 날짜                | 무슨 일이 일어나나요?                                                                                             |
| ----------------- | -------------------------------------------------------------------------------------------------------- |
| **2026년 10월 16일** | Kaia 체인에 대한 모든 Ankr RPC 엔드포인트가 중단되었습니다. 요청에서 더 이상 데이터가 반환되지 않습니다.        |
| 해가 진 뒤            | Kaia는 더 이상 Ankr를 통해 이용할 수 없습니다. 기존 API 키와 요금제는 더 이상 Kaia 트래픽을 처리하지 않습니다. |

**영향을 받지 않는 사항:**

- 카이아 메인넷(8217)과 카이로스 테스트넷(1001) 자체
- 귀하의 계약서, 주소, 잔액 및 온체인 내역
- 앱에서 Ankr을 호출하지 않는 모든 부분

모든 RPC 제공자는 동일한 체인 데이터를 제공합니다. 앱에서 다른 엔드포인트를 지정해도 동일한 결과가 반환됩니다.

## 여러분도 영향을 받고 계신가요?

다음 중 하나라도 해당된다면 귀하도 영향을 받게 됩니다:

- 사용자의 앱, 스크립트 또는 CI는 `rpc.ankr.com` 하위 호스트로 Kaia JSON-RPC 호출을 전송합니다.
- Ankr 프로젝트의 지갑 구성, Hardhat/Foundry 네트워크 항목 또는 SDK 제공자 URL.
- 스택 내의 종속성, 인덱서, 대시보드 또는 분석 작업이 Ankr을 통해 Kaia의 데이터를 읽습니다.

코드베이스를 빠르게 확인하는 방법:

```bash
grep -rn "ankr" --include="*.ts" --include="*.js" --include="*.json" --include="*.toml" --include="*.yaml" --include="*.yml" --include="*.env*" .
```

또한 grep이 접근할 수 없는 곳, 즉 배포 환경 변수, CI/CD 시크릿, 서버리스 함수 구성, 그리고 지갑이나 호스팅된 대시보드에 저장된 RPC URL 등도 확인해 보세요.

이미 Kaia Foundation의 공개 엔드포인트나 다른 제공업체를 사용하고 계신 경우, 이 조치의 영향을 **받지 않습니다**.

:::tip 2026년 10월 16일 이전에 이 작업을 완료해 주세요.

Ankr 계정이 아직 활성화된 상태인 동안:

- 프로젝트에서 사용하는 Ankr 엔드포인트와 API 키를 기록해 두면, 업데이트가 필요한 모든 부분을 찾을 수 있습니다.
- Ankr 대시보드에서 보관하고 싶은 사용 내역이나 분석 데이터를 내보내세요.
- 이관 절차가 완료되면 Ankr 구독을 해지하여, 더 이상 사용하지 않는 서비스에 대한 요금이 청구되지 않도록 하세요.

:::

## 대안을 선택하세요

아래에 나열된 모든 의료진이 오늘 카이아를 진료하고 있습니다. 모두 동일한 JSON-RPC 인터페이스를 사용하기 때문에, 마이그레이션은 코드 변경이 아닌 URL 변경만으로 이루어집니다.

|               | [연금술](https://www.alchemy.com/rpc/kaia) **(추천)** | [QuickNode](https://www.quicknode.com/docs/kaia) | [All That Node](https://www.allthatnode.com/) | [dRPC](https://drpc.org/) | 카이아 재단       |
| ------------- | ------------------------------------------------------------------- | ------------------------------------------------ | --------------------------------------------- | ------------------------- | ------------ |
| **호스팅**       | 관리형                                                                 | 관리형                                              | 관리형                                           | 관리형                       | 공공, 지역사회 주도의 |
| **API 키 필요**  | 네                                                                   | 네                                                | 네                                             | 아니요, 공개 엔드포인트의 경우         | 아니요          |
| **이주 활동**     | URL을 바꾸세요                                                           | URL을 바꾸세요                                        | URL을 바꾸세요                                     | URL을 바꾸세요                 | URL을 바꾸세요    |
| **가장 적합한 대상** | 가장 많은 마이그레이션                                                        | 전용 엔드포인트가 필요한 프로덕션 앱                             | 노드와 페이크트 툴링을 원하는 팀                            | 가장 빠른 시작, 회원가입 불필요        | 개발 및 테스트     |

아카이브 기록 및 `debug` / `trace` 네임스페이스와 같은 기능은 제공업체와 요금제에 따라 다릅니다. 결정하기 전에 해당 서비스 제공업체의 공식 문서를 통해 워크로드에 필요한 사항을 확인하세요. 표 머리글에 있는 링크가 각 항목에 대한 공식 정보 출처입니다.

**알케미는 Ankr을 대체하려는 대부분의 팀에게 권장되는 대안입니다.**

엔드포인트 URL 및 Kaia를 지원하는 RPC 제공자의 전체 목록은 [공개 JSON RPC 엔드포인트](./public-en.md)를 참조하십시오. 선택한 서비스 제공업체에 가입한 다음, 앱 내의 Ankr URL을 해당 업체에서 제공한 엔드포인트로 교체하세요.

호스팅 서비스 제공업체에 전혀 의존하고 싶지 않다면 [직접 엔드포인트 노드를 운영](../nodes/endpoint-node/endpoint-node.md)할 수도 있습니다.
